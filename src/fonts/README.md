# jua-menu.woff2

메뉴판 간판에 쓰는 **주아체(Jua)**.
Google Fonts 에서 받았고 라이선스는 **SIL Open Font License 1.1** 이다.
https://fonts.google.com/specimen/Jua

"메뉴판" 세 글자만 남기고 잘라낸 부분집합이라 **6.6 KB** 다.
다른 글자를 쓰면 글꼴이 적용되지 않고 시스템 글꼴로 떨어진다.
글자를 늘려야 하면 아래로 다시 받는다.

```
curl "https://fonts.googleapis.com/css2?family=Jua&text=<쓸 글자>"
```

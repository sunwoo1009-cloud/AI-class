# tools — 개발용 스크립트

## gen-seed.mjs

확인용 샘플 데이터를 만든다. 8주치 체크인 18건과 주간 회기 수가 들어 있어서,
주간 요약·에스컬레이션·돌아보기·캘린더 화면이 모두 채워진 상태로 보인다.

```bash
node tools/gen-seed.mjs .
```

프로젝트 루트에 두 파일이 생긴다 (둘 다 `.gitignore`에 있다).

| 파일 | 쓰임 |
|---|---|
| `sample-data.js` | 내용을 복사해 **브라우저 개발자도구 Console에 붙여넣는다** |
| `seed.json` | 같은 데이터의 JSON. 계산 검증용 |

날짜는 **실행한 날 기준**으로 만들어진다. 그래서 돌릴 때마다 "최근 7일",
"최근 4주" 같은 구간이 항상 맞아떨어진다.

기존 기록을 덮어쓰므로, 직접 해본 체크인을 남기고 싶으면 먼저 설정에서
내보내기를 하거나 다른 브라우저에서 넣는다.

샘플은 일부러 이렇게 짜여 있다.

- 에스컬레이션 세 조건(7.2절)이 **모두** 걸린다
- 돌아보기에서 최근 4주(2.1점)가 그 전 4주(1.0점)보다 **잘 내려간다**
  — 조절이 늘어난 모습. 반대 상황(비귀인 문구)을 보려면 값을 뒤집으면 된다
